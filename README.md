# Logic Gates Pro — Διαδραστική Πλατφόρμα Εκμάθησης Λογικών Πυλών & Σχεδιασμού Κυκλωμάτων

Μια σύγχρονη, πλήρως διαδραστική και ανοιχτού κώδικα (Open Source) εφαρμογή web για την εκμάθηση ψηφιακής λογικής, πυλών Boolean (AND, OR, NOT, NAND, NOR, XOR, XNOR), κανόνων De Morgan, πινάκων αληθείας και σχεδιασμού ψηφιακών κυκλωμάτων σε πραγματικό χρόνο με gamification (XP, επίπεδα, σερί, σήματα).

---

## 🌟 Κύριες Δυνατότητες (Features)

1. **Διαδραστικά Μαθήματα (Lessons)**:
   - Βήμα-προς-βήμα ανάλυση βασικών πυλών (AND, OR, NOT).
   - Σύνθετες πύλες (NAND, NOR, XOR, XNOR) και οικουμενικές πύλες (Universal Gates).
   - Άλγεβρα Boole, ταυτότητες & θεωρήματα De Morgan.
   - Κυκλώματα προσθετών (Half Adder, Full Adder, Πολυπλέκτες Multiplexer).
   - Ενσωματωμένος ζωντανός προσομοιωτής μέσα σε κάθε μάθημα.

2. **Ασκήσεις & Quiz (Exercises)**:
   - **Υπολογισμός Εξόδου Πύλης**: Διαδραστική εύρεση εξόδου με οπτικά διαγράμματα.
   - **Απλοποίηση Εκφράσεων**: Ερωτήσεις πολλαπλής επιλογής για άλγεβρα Boole & De Morgan.
   - **Διαδραστικός Πίνακας Αληθείας (Truth Table)**: Συμπλήρωση κελιών με δυναμικό έλεγχο ορθότητας.
   - **Λειτουργία Χρονομέτρησης (Speed Challenge)**: Δοκιμασία ταχύτητας 60 δευτερολέπτων με multipliers πόντων!

3. **Σχεδιαστής Κυκλωμάτων (Circuit Designer / Simulator)**:
   - Τοποθέτηση εισόδων (Διακόπτες ON/OFF, Σταθερές 1/0, Παλμογεννήτρια Ρολογιού Clock).
   - Τοποθέτηση όλων των λογικών πυλών και εξόδων (Λάμπες LED, Probe/Μετρητές).
   - Σύνδεση με δυναμικά καμπύλα καλώδια (wires) και φωτεινή ένδειξη σήματος (High/Low).
   - Έτοιμα πρότυπα κυκλωμάτων (Half Adder, Full Adder, XOR από NAND, 2-to-1 MUX, SR Latch, Majority Voter).
   - Αυτόματη παραγωγή Πίνακα Αληθείας (Truth Table Generator) για ολόκληρο το σχεδιασμένο κύκλωμα!

4. **Gamification & Προφίλ Χρήστη**:
   - Σύστημα πόντων εμπειρίας (XP) και εξέλιξη επιπέδων (Level 1 έως Level 10+).
   - Συνεχόμενες σωστές απαντήσεις (Streak) με πολλαπλασιαστή XP (+20%, +50%, +100%).
   - 12 μοναδικά ξεκλειδώσιμα Σήματα / Επιτεύγματα (Badges).
   - Εβδομαδιαίο γράφημα δραστηριότητας και αναλυτικά στατιστικά ακρίβειας.

5. **Υποστήριξη Θεμάτων (Light / Dark Mode)**:
   - Άμεση εναλλαγή μεταξύ Φωτεινού και Σκούρου θέματος με το πάτημα ενός κουμπιού (☀️ / 🌙) στην πάνω μπάρα.
   - Πλήρης προσαρμογή χρωματικής αντίθεσης σε όλες τις σελίδες και τα εργαλεία.

6. **Πολυγλωσσική Υποστήριξη**:
   - Πλήρης υποστήριξη Ελληνικών (🇬🇷) και Αγγλικών (🇬🇧) με άμεση εναλλαγή.

## 🚀 Οδηγός Εγκατάστασης & Εκτέλεσης (Installation & Running Guide)

### Προαπαιτούμενα
- **Node.js** (έκδοση `v18.0.0` ή νεότερη συνιστάται)
- **npm** (περιλαμβάνεται με το Node.js) ή **yarn** / **pnpm** / **bun**

### Βήμα 1: Λήψη ή Κλωνοποίηση του Κώδικα
Ανοίξτε το τερματικό σας (Terminal / Command Prompt) στον φάκελο του έργου:
```bash
git clone <repository-url>
cd <project-folder>
```

### Βήμα 2: Εγκατάσταση Εξαρτήσεων (Dependencies)
Εκτελέστε την παρακάτω εντολή για να εγκατασταθούν όλες οι βιβλιοθήκες:
```bash
npm install
```

### Βήμα 3: Εκτέλεση σε Περιβάλλον Ανάπτυξης (Development Server)
Για να εκκινήσετε την εφαρμογή τοπικά στον υπολογιστή σας:
```bash
npm run dev
```
Η εφαρμογή θα ξεκινήσει και θα είναι διαθέσιμη στη διεύθυνση:
👉 `http://localhost:3000` (ή στη θύρα που θα υποδείξει το τερματικό).

### Βήμα 4: Δημιουργία Έκδοσης Παραγωγής (Production Build)
Για να ετοιμάσετε τα βελτιστοποιημένα στατικά αρχεία παραγωγής:
```bash
npm run build
```
Τα παραγόμενα αρχεία θα αποθηκευτούν στον φάκελο `dist/`.

### Βήμα 5: Προεπισκόπηση Έκδοσης Παραγωγής (Preview)
```bash
npm run preview
```

### Βήμα 6: Έλεγχος Τύπων TypeScript (Linting)
```bash
npm run lint
```

## 📖 Οδηγός Χρήσης της Εφαρμογής (User Guide)

### 1. Περιήγηση (Navigation)
- Στην επάνω γραμμή πλοήγησης μπορείτε ανά πάσα στιγμή να μεταβείτε στις ενότητες: **Αρχική**, **Μαθήματα**, **Ασκήσεις**, **Σχεδιαστής** και **Προφίλ**.
- Στο δεξί μέρος της μπάρας μπορείτε:
  - Να παρακολουθείτε το τρέχον **Σερί (Streak)** και το **Επίπεδο/XP**.
  - Να πατήσετε το εικονίδιο **☀️ / 🌙** για άμεση αλλαγή μεταξύ Φωτεινού και Σκούρου θέματος.
  - Να πατήσετε το εικονίδιο **🔊 / 🔇** για ενεργοποίηση/απενεργοποίηση ηχητικών εφέ.
  - Να αλλάξετε γλώσσα μεταξύ **🇬🇷 EL** και **🇬🇧 EN**.

### 2. Παρακολούθηση Μαθημάτων (Lessons)
- Επιλέξτε οποιοδήποτε μάθημα από τη λίστα.
- Διαβάστε τη θεωρία, δείτε τους μαθηματικούς τύπους και τον πίνακα αληθείας.
- Χρησιμοποιήστε το ενσωματωμένο διαδραστικό εργαλείο δοκιμής για να αλλάξετε τις εισόδους (0 και 1) και να δείτε την έξοδο σε πραγματικό χρόνο.
- Πατήστε **«Σημείωση ως Ολοκληρωμένο»** για να κατοχυρώσετε +50 XP.

### 3. Επίλυση Ασκήσεων & Timed Speed Challenge (Exercises)
- **Ελεύθερη Εξάσκηση**: Επιλέξτε τη σωστή τιμή εξόδου, την απλοποιημένη έκφραση Boole ή συμπληρώστε τα κενά στον πίνακα αληθείας. Κάθε σωστή απάντηση αυξάνει το σερί και τους πόντους σας.
- **Πρόκληση Ταχύτητας (Timed Challenge)**: Πατήστε την καρτέλα με τον κεραυνό ⚡ για να ξεκινήσετε μια δοκιμασία 60 δευτερολέπτων με μέγιστη συγκέντρωση πόντων!

### 4. Χρήση του Σχεδιαστή Κυκλωμάτων (Circuit Designer)
- **Προσθήκη Στοιχείων**: Κάντε κλικ σε οποιοδήποτε στοιχείο από την αριστερή βιβλιοθήκη (Είσοδοι, Πύλες, Έξοδοι).
- **Μετακίνηση**: Σύρετε με το ποντίκι τα εξαρτήματα στον καμβά.
- **Καλωδίωση (Wiring)**: 
  1. Κάντε κλικ στον πράσινο/γκρι κύκλο εξόδου ενός στοιχείου (στα δεξιά του).
  2. Κάντε κλικ στον κύκλο εισόδου ενός άλλου στοιχείου (στα αριστερά του).
  3. Το καλώδιο θα συνδεθεί αυτόματα και θα μεταφέρει το ψηφιακό σήμα!
- **Διαγραφή Καλωδίου**: Κάντε κλικ πάνω στο καλώδιο που θέλετε να αφαιρέσετε.
- **Αλλαγή Εισόδου**: Κάντε κλικ πάνω σε έναν διακόπτη (Switch) για να αλλάξετε την κατάστασή του μεταξύ 0 (OFF) και 1 (ON).
- **Έτοιμα Κυκλώματα**: Πατήστε το κουμπί **«Έτοιμα Κυκλώματα»** για να φορτώσετε άμεσα δομές όπως Half Adder, Full Adder, SR Latch κ.ά.
- **Πίνακας Αληθείας**: Πατήστε το κουμπί **«Πίνακας Αληθείας»** για να δείτε αυτόματα όλους τους πιθανούς συνδυασμούς εισόδων και τις αντίστοιχες εξόδους του κυκλώματός σας!

### 5. Παρακολούθηση Προόδου & Προφίλ (Profile)
- Αλλάξτε το όνομα χρήστη και το Avatar σας.
- Δείτε τα σήματα που έχετε ξεκλειδώσει και τις προϋποθέσεις για τα υπόλοιπα.
- Ελέγξτε το ποσοστό επιτυχίας, το μέγιστο σερί και τα ιστορικά δεδομένα εξάσκησης.
